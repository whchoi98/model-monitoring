# Frontend Components

## Role
React UI components for the monitoring dashboard (monitoring panels, shared UI primitives, and a `chat/` subfolder). All are client components (`"use client"`).

Value, unit and marker are separate flex items (`flex-wrap`) so a narrow 320px column wraps before the marker instead of overflowing into the next value. Change thresholds only in `metricGrade.ts`.

## Shared state and presentation
- Root `Providers` owns language/authentication. `AppShell` provides navigation, a page title, public content, and chat; `useAuth` opens one shared login dialog.
- `useAsyncResource` binds data to its query, aborts superseded reads, and preserves same-query results on failed refresh. Use `DataState` and `RefreshControls` for visible recovery.
- `Dialog` supplies native modal focus/Escape/return behavior. `usePageTitle` prevents streamed fallback metadata from replacing the localized active title.
- `MonitoringOverview` distinguishes coverage, observed success, and attention. Missing catalog counts remain unknown or use the collector's explicit expected count.
- Charts retain real time intervals and missing-value gaps; `isolatedSampleTimes` keeps isolated successes visible in dense series.

## Patterns
- Color coding: emerald (good) → amber (warning) → rose (bad) — channel health (`HealthBadge`) and status palettes
- Metric **value** grades on dashboard cards use a different palette by user request: **blue** (normal) → amber ▲ (warning) → rose ◆ (critical), from `lib/metricGrade.ts` (ADR-029). Do not swap the normal blue for emerald — blue means "fast value", emerald means "healthy channel". Likewise the KO grade name is 양호 (not 정상, the `HealthBadge` word), pinned by `metricGrade.test.ts`
- `model_name` labels carry a `"Bedrock <family> (<channel>)"` / `"Anthropic <family> (US)"` / `"OpenAI <family> (<region>|Global|US|1P)"` prefix;
  `TrendChart` `MODEL_COLORS` keys must match these labels byte-for-byte. `lib/sortModels.ts` `FAMILY_ORDER` entries are matched with `includes`, so a longer family name (Fable 5.1, Opus 5.5) must precede its prefix (Fable 5, Opus 5)
- Sort order: Anthropic → Global(Bedrock·OpenAI `(Global)` 공통) → US(Bedrock US·OpenAI US CRIS) → OpenAI 리전, family newest-first (`sortModels.ts` `channelRank`/`familyRank`)
- Auto-refresh via `useAutoRefresh` hook with countdown — default 30 s (`AutoDashboard`, `CostDashboardPanel`, `ReliabilityPanel`, `EfficiencyPanel`, `AnalysisPanel`); 60 s for `ParityPanel`, `GptOnAwsPanel`, `ClaudeFeaturesPanel`
