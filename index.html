Why

왜 Bedrock LLM Monitor인가

멀티 프로바이더 시대에 "어느 경로로 어떤 모델을 쓸지"는 벤치마크 기사가 아니라 내 워크로드의 실측 데이터로 정해야 합니다.

실측 기반 판정

모든 지표와 패리티 셀은 5분/12시간마다 실제 API 호출로 만들어집니다. 추정치·문서 인용이 아닙니다.

동일 조건 채널 비교

같은 모델 패밀리를 Bedrock Global/US, CP on AWS, Mantle, 1P direct로 병렬 호출해 진짜 사과-대-사과 비교를 제공합니다.

비용·신뢰성까지 한 화면

30일 비용 예측, 채널별 성공률·에러 버킷, 0-100 토큰 효율 점수를 성능 지표와 함께 봅니다.

AI가 요약하는 이상 징후

Claude 챗봇에 자연어로 질의하고, 자동 인사이트 잡이 이상 징후를 한국어로 요약합니다.

패리티 런의 원칙 — "HTTP 200은 증거가 아니다." 도구 카나리 왕복, JSON 파싱, 캐시 토큰 카운트 같은 응답 내용 검사를 통과해야 Supported이며, 셀을 클릭하면 Request/Response JSON 증거가 그대로 열립니다.
Features

기능

⏱️ 실시간 자동 프로빙

EventBridge → Fargate가 5분마다 6개 워크로드(대화·추론·코드·요약·JSON·창작)를 라운드로빈 실측.

📈 트렌드 차트

TTFT·총 지연·TPS 시계열을 모델 다중 선택·조회 기간·워크로드 필터로 비교.

🔬 피처 패리티 매트릭스

모델 × 6 API surface × 19 피처를 실행-증거로 판정. 접이식 그룹 + 상태 분포 막대.

🧾 증거 모달

셀 클릭 → 판정 근거와 Request/Response JSON. 직전 런 대비 변경(diff)은 상단 배너로.

🧭 모델 탐색

모델 카드별 호출 ID·단가·문서 링크 + Converse/InvokeModel/Messages/Responses 코드 예제.

💰 비용 분석

30일 비용 예측, 모델별·채널별 비교, 토큰 단가표 기반 산정.

🛡️ 신뢰성

패밀리/채널별 성공률과 에러 버킷 — 순간 장애도 12시간 패리티 런에 기록됩니다.

⚡ 효율성 점수

워크로드 카테고리별 0-100 가중 토큰 효율 점수.

📊 출력 분석

stop reason 분포와 출력 길이 히스토그램으로 응답 품질 패턴 관찰.

🤖 AI 챗봇·인사이트

Claude + 4개 도구로 시계열 자연어 질의, 5분마다 자동 인사이트 요약.

🚨 이상 징후 배너

최근 12시간 프로브 실패를 대시보드 최상단에 모델별로 요약.

📱 모바일·테마·다국어

반응형 레이아웃(햄버거 내비), 다크/화이트 테마, KO/EN 전환.

How it works

동작 원리

수집

EventBridge Scheduler가 Fargate one-shot 태스크를 기동 — 5분 프로브 + 12시간 패리티 스윕(~750 프로브).

판정

응답 내용 검사(카나리 왕복·JSON·캐시 토큰·스트림 델타)로 Supported/Unsupported/Broken 분류. 명시적 거부는 미지원, 그 외 오류는 Broken.

저장

RDS PostgreSQL에 지표·판정·증거(JSON) 저장. 60일 초과분은 시간별 집계로 이관.

시각화·알림

Next.js 대시보드 8개 페이지 + 런 간 변경 diff 배너 + AI 인사이트 요약 + CloudWatch 알람.

Stack

기술 스택
