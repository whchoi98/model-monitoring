## 한국어

구성과 운영 절차는 아키텍처·배포·롤백 문서를 참고한다. 로컬 환경과 검증 명령은
온보딩 문서에, 인증과 응답 계약은 API 문서에 있다. UI 개선 내용과 회귀 검증은
모니터링 UX 리뷰에 기록되어 있다. 변경 이력은 저장소 루트의 CHANGELOG가 기준이다.
