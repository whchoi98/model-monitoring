# 사용자 중심 웹 UI 전면 개편

기준: v2.35.1, `bc34c77`. 요청: 웹페이지 전체 디자인을 사용자 편의성에 맞게 다시 구현한다.

## 사용 목적과 관찰

사용자는 모델 운영 상태를 확인하고, 성능·비용·지원 기능을 비교하며, 필요할 때 직접 프로브와 AI 분석을 실행한다. 현재 대시보드에서는 요약 카드, 주의 채널, 전체 채널 상태, 수집 정보, 워크로드, 실패 이력이 세로로 이어져 1440px 화면의 첫 화면에 모델별 결과가 나오지 않는다. 나머지 화면도 제목, 설명, 필터, 갱신 정보와 결과의 배치가 제각각이고 작은 글씨가 많다.

## 확정 방향

- 가운데 정렬된 상단 메뉴와 Dashboard 다음 Unit Prices 순서를 유지한다.
- 공통 헤더, 페이지 제목, 필터 도구 모음, 통계 카드, 데이터 패널, 표, 대화상자를 하나의 시각 체계로 재구현한다.
- 기본안은 라이트 테마다. 기존에 저장된 다크/라이트 선택을 우선하며 두 테마 모두 완성한다. 사용자에게 기본 테마 선호를 선택할 기회를 주었고, 답변이 오면 반영한다.
- 대시보드의 첫 화면에서 실제 모델 결과를 찾을 수 있게 한다. 전체 상태를 보여주는 간결한 통계 행 다음에 모델 목록과 보조 분석 영역을 배치한다. 수집 정보·주의 채널·AI 분석을 긴 선행 블록으로 쌓지 않는다.
- 페이지 찾기는 상단의 ‘빠른 이동’ 버튼과 Ctrl/Cmd+K 대화상자로 제공한다. 기존 12개 페이지를 검색하며 서버 검색이나 새 백엔드 기능을 만들지 않는다.
- 핵심 정보는 바로 보이고, 긴 설명과 상세 AI 본문은 사용자가 펼쳐 읽는다. 기존 정보와 기능은 모두 접근 가능해야 한다.

## 시각 체계

‘데이터를 읽는 작업 공간’으로 디자인한다. 마케팅용 문구, 장식용 가짜 차트, 큰 배경 그라데이션을 넣지 않는다.

- 밝은 바탕 `#F5F7FB`, 패널 `#FFFFFF`, 본문 `#17243B`, 보조 글자 `#53647D`, 경계 `#DCE4EF`, 주요 동작 `#2563EB`.
- 다크는 잉크색 바탕 `#101827`, 패널 `#172338`, 명확한 중간 경계와 읽기 쉬운 보조 글자를 쓴다.
- 기존 Inter와 한국어 시스템 글꼴을 유지하되 제목은 28–32px, 본문·조작부는 14px 이상을 기준으로 한다. 작은 보조 정보도 대개 12–13px를 사용한다. 숫자는 tabular-nums로 정렬한다.
- 페이지 최대 폭은 1680px, 모바일 여백은 16px, 큰 화면 여백은 24–32px. 패널 간격은 20–24px, 카드 반경은 14–16px, 컨트롤 반경은 8–10px.
- 공통 패널 제목과 작은 분류 라벨, 정렬된 숫자 열을 시각적 특징으로 삼는다. 선택 상태는 선명한 파란색이며, 기존 상태·지표 등급의 의미는 바꾸지 않는다.
- 모바일에서는 페이지 전체가 가로로 넘치지 않는다. 넓은 표만 자체 영역에서 스크롤한다. 포커스, 터치 대상, 화면 끝 여유, reduced-motion, PWA safe-area를 유지한다.

## 화면 범위

1. 공통: 헤더·메뉴·빠른 이동·테마·페이지 틀·버튼·입력·필터·대화상자·로딩/오류/빈 상태·갱신 정보·푸터.
2. 대시보드: 요약, 상태 목록/카드, 채널 선택, 주의 채널, 수집 상태, 워크로드, 추세, 비교 도크, AI 분석, 지표/채널 안내.
3. 분석: 비용, 신뢰성, 효율성, 출력 분석. 비교 가능한 카드와 그래프, 일관된 필터 위치.
4. 탐색/검증: 모델 탐색, 단가표, 패리티, GPT on AWS, Claude API 기능. 명확한 읽기 순서, 필터·범례·증거 접근, 긴 표/코드의 안전한 스크롤.
5. 실행: 수동 프로브, 모델 선택, 프롬프트, 결과/차트/비교, 이력, 로그인·가입, 챗봇 팝업/모달.

## 보존 계약

- API URL, 인증, 데이터 수집, 비용 계산, 모델 카탈로그, 정렬·채널 의미, 지표 임계값을 바꾸지 않는다.
- AI 모델은 Sonnet 5.5, 후속 질문은 Haiku 4.5다.
- 접속 통계는 기존 서버 값이며 10,000을 다시 더하지 않는다. 초기값 설명 문구를 다시 넣지 않는다.
- 언어는 한국어 기본 + 영어. 새 공통 문구는 i18n.ts에 두고 기존 페이지의 언어 처리 방식도 존중한다.
- query string의 검색/필터/워크로드/기간/레이아웃/선택 모델과 뒤로 가기·새로고침 동작을 유지한다.
- 공용 페이지의 헤더는 AppShell이 렌더링하는 AppHeader 하나다. /chat만 독립 팝업이다.
- FloatingChat의 스크롤 숨김, 키보드 접근, 비교 도크 여유 공간을 유지한다.
- 모델 값의 양호/경고/위험 색은 파랑/호박/장미색이다. 채널 정상 상태의 녹색과 섞지 않는다.
- 공개 조회는 인증 검사가 끝나기를 기다리지 않는다. 오류와 성공한 빈 결과는 구분한다.
- 기존 테스트를 삭제하거나 검증을 느슨하게 해서 통과시키지 않는다. 디자인에 따른 레이아웃 기대 변경은 근거를 남긴다.

## 검증과 완료

make verify, 실제 production 빌드, Chromium/WebKit 기존 회귀, 새 탐색/테마 동작 검사, 한국어/영어·라이트/다크·모바일/데스크톱 화면 검토를 마친다. 모든 주요 페이지를 새 공통 컴포넌트와 배치로 확인하며 부분적인 색상 변경으로 끝내지 않는다.

v2.36.0의 모든 버전 표기를 맞추고 현재 AWS 상태에서 이미지 digest와 RUM 설정을 확인해 배포한다. 백엔드 버전 표기로 공유 이미지가 바뀌므로 backend 서비스와 6개 스케줄을 함께 갱신한다. 운영 화면·API·접속수 보존을 확인한 뒤 기존 main에 통합하고 커밋·푸시한다.
