# v2.44.2 운영 배포 기록

배포일: 2026-11-21 UTC. 배포 16:55–16:59, 확인 16:59–17:10.

`/parity`와 `/claude-features`에서 증거 영역이 저절로 접히고 Key Findings 드로어 버튼이 키보드 포커스를 잃던 프런트엔드 버그를 고친
v2.44.2를 운영에 반영했다(사용자 승인 2026-11-21). 문서 릴리스였던 v2.44.1의 버전 문자열도 이 배포로 함께 나갔다. CDK 코드, env, IAM,
DB 스키마 변경은 없고, backend 소스는 운영 중이던 v2.44.0 대비 FastAPI 버전 문자열 한 줄만 다르다. 릴리스 절차대로 두 이미지를 같은 태그로
빌드해 digest 고정 CDK로 AppServices와 Scheduler 두 스택을 배포했다. 롤백 지점은 v2.44.0 이미지 `vb4d374e`(backend `:99`, frontend `:104`,
`docs/reviews/2026-11-18-v244-deployment.md`)이다.

## 원인과 수정

- 증거 대화상자의 접이식 영역(`Section`, `ParityPanel.tsx`와 `ClaudeFeaturesPanel.tsx`)과 Key Findings 드로어의 조각(`Sec`, `GroupCards`,
  `Chips`, `ClaudeFeaturesPanel.tsx`)이 렌더 함수 안에서 만든 컴포넌트였다.
- 두 화면은 자동 새로고침 카운트다운(`useAutoRefresh`, v2.26.0부터) 때문에 1초마다 다시 그려진다. 렌더 안에서 만든 컴포넌트는 렌더마다 새
  컴포넌트 타입이라 React가 그 아래 DOM을 1초마다 새로 만들었고, `<details>`의 열림 상태와 포커스가 함께 사라졌다.
- 컴포넌트를 모듈 최상위로 옮겼다(`components/EvidenceSection.tsx`, `FindingSection`, `FindingGroupCards`, `FindingChips`). 마크업, 클래스,
  문구는 그대로다.

## 후속

- `tests/test_insights_bedrock.py`의 로그 테스트는 같은 날 main CI(PR #83 병합 뒤)와 개발 호스트 `make verify`에서 한 번씩 실패했다. 원인은 고치지 않았다.
