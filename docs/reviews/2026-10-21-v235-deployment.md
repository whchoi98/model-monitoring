**접속 통계 확인**

공개 사이트의 실제 브라우저에서 초기값 `10,000`을 확인했다. 검증 시 총 접속수는 `10,002`이었고,
가격표로 이동하고 새로고침한 뒤에도 `10,002`으로 유지됐다. 방문자 쿠키도 동일했다.
현재 접속은 최근 90초의 활동 브라우저 기준이며, 누적값은 PostgreSQL에 보존한다.
쿠키의 Secure·HttpOnly·SameSite=Lax·`/api/presence` 경로와 집계 API의 `no-store` 응답을 확인했다.

RUM SDK가 로드됐고 실제 수집 요청 두 건이 HTTP 200으로 처리됐다. 키와 쿠키 값은 기록하지 않았다.
공개 페이지에서 JavaScript 오류는 관찰되지 않았다. 자동 수집 API는 66채널과 수집 진행 상태를 반환했다.
