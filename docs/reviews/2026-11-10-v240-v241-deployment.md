## 관찰 — Bedrock Fable 5.2의 기본 추론이 본문을 늦춘다

첫 새 회차(코드 생성 워크로드)에서 Bedrock Fable 5.2 Global, US 두 행이 `success`인데 `ttft_ms`, `tps`가 비고 출력 텍스트가 없었다
(`output_tokens` 400, `stop_reason` max_tokens). 같은 회차의 CP Fable 5.2와 Bedrock Fable 5.1은 코드를 출력했다.

- 원인: Bedrock Converse에서 Fable 5.x는 기본으로 adaptive thinking을 하고(`reasoningContent` delta, 요약 텍스트는 비어 있다), 프로버는
  `text` delta만 TTFT와 본문으로 센다. Fable 5.2는 코드 생성에서 400토큰을 추론에 다 써 본문에 닿지 못한다(한도 2000이면 1,175토큰에 끝난다).
- 범위(2026-11-10 워크로드 6개 실측, Global): Fable 5.2는 추론(512)과 코드 생성(400)에서 본문 없음, 짧은 대화, 요약, JSON 추출, 번역은 정상.
  Fable 5.1도 추론(512)에서는 이미 같은 현상이다 — 기존 측정 규칙의 한계가 Fable 5.2에서 한 워크로드 더 드러났다.
- `thinking.type.disabled`는 400("not supported for this model")이고, `output_config.effort: low`를 보내면 코드 생성에서도 약 2초에 본문이 나온다.
- 사용자 결정(2026-11-10): 그대로 둔다 — 모든 모델에 같은 요청 규칙을 유지한다(코드 변경 없음, ADR-036 Consequences).
