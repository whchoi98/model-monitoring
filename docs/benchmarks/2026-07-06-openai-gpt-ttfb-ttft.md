### 핵심 결론

1. **1차 측정 결론 재현** — gpt-5.4 기준 1P가 Mantle 대비 TTFB **2.1–2.9×**, TTFT **2.1–3.0×**, GAP **2.1–3.3×** 빠름 (1차: 2.0–2.7× / 2.2–3.5× / 2.2–4.0×). Mantle 내 TTFB 리전 순서(us-west-2 < us-east-2 < us-east-1)도 동일.
2. **TTFB 재현성이 매우 높음** — 7채널 전부 1차 측정 대비 **±7% 이내** (1P 5.4: 410→382, west-2: 830→789, east-2: 1,005→1,011, east-1: 1,090→1,094). 네트워크 경로 특성은 안정적.
3. **신규: 1P gpt-5.5는 "절반의 이점"** — TTFB는 364ms로 gpt-5.4(382ms)와 동급으로 빠르지만, thinking GAP이 2,017ms로 gpt-5.4(859ms)의 2.3배. Mantle gpt-5.5의 GAP(2,186–2,618ms)과 격차가 8–30%로 좁혀짐. 즉 **gpt-5.5에서 1P의 이점은 대부분 전송(TTFB)이고, gpt-5.4처럼 thinking까지 2×+ 빠르지는 않음** (§5.3).
4. **TTFT 변동은 여전히 thinking이 지배** — 1차 대비 TTFT median이 east-2 5.4는 −39%(4,423→2,715), east-1 5.4는 +20%(3,284→3,930)로 크게 움직였지만 TTFB는 그대로 → 전부 GAP(thinking) 변동. GAP↔reasoning_tokens Pearson r=0.315 (n=137).
5. **Mantle prompt cache flapping 지속, 1P는 완벽** — 1P는 40/40 히트(매 호출 cached=55,552). Mantle은 채널당 2–12회 미스. 캐시 미스 비용은 TTFT median 기준 **+0.8–1.8초** (§5.4).
6. **신규 관찰: Mantle에서 3/100 호출이 무출력(silent no-output) 종료** — TTFB 수신 후 텍스트 delta·usage 없이 스트림 종료(예외 없음). us-east-2 gpt-5.5 2회, us-west-2 gpt-5.4 1회. 1P는 40/40 정상 (§5.5).

1P는 완벽한 캐시 안정성(1차와 동일). Mantle flapping도 1차와 동일 — 특히 us-east-2 gpt-5.5는 20회 중 12회 미스. 미스 비용은 표본이 유의미한 채널 기준 TTFT +0.8–1.8s. (역전된 2개 채널은 미스 표본이 적거나 thinking 변동이 캐시 효과를 덮은 경우.)

### 5.5 무출력(silent no-output) 종료 — 신규 관찰

Mantle 100회 중 **3회**(us-east-2 gpt-5.5 run 6·17, us-west-2 gpt-5.4 run 3)에서 TTFB(첫 이벤트)는 정상 수신했으나 이후 **텍스트 delta·completed 이벤트·usage 없이 스트림이 조용히 종료** (SDK 예외 없음). 1P는 40/40 정상.

- 모니터링 함의: autoprober가 동일 패턴을 만나면 "성공했지만 출력 0"으로 기록될 수 있음 — probe 로직에서 output_tokens=0 + stop_reason 없음 조합을 오류로 분류하는지 점검 가치.
- 1차 측정(50회)에서는 미관찰 → 발생률 ~3%의 간헐 이슈로 추정, 더 큰 N으로 재확인 필요.

## 6. 분석 요약

1. **1P 우위·리전 순서·캐시 특성 모두 재현** — 채널 선택 관점에서 1차 결론 그대로 유효.
2. **TTFB는 채널의 고유 상수처럼 동작** (±7% 재현). TTFT 비교는 N=20에서도 thinking 변동에 휘둘림 — 채널 간 TTFT 비교는 GAP 분해 없이는 오독 위험.
3. **gpt-5.5는 1P에서도 thinking이 느려** first-token 체감은 gpt-5.4 1P가 독보적 (TTFT 1.3s vs 2.4s+).
4. **Mantle의 간헐 무출력 종료(3%)와 캐시 flapping**은 운영 신뢰성 관점에서 1P 대비 열위 — 단, 과금·거버넌스·데이터 경로가 다른 별개 채널임은 1차와 동일한 유의사항.
